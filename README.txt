MY GYM TRACKER — RED + BLACK EDITION

A personal, iPhone-friendly gym tracker.

NEW: Tap Train → Add exercise to browse/search the exercise library. Pick an exercise, choose sets and reps, and add it to any day. Use Sets & reps or Remove on existing exercises. Create custom exercises too. Original plan stays as the starting template.

To use on iPhone: upload all files in this folder to an HTTPS static site such as GitHub Pages. Open the resulting link in Safari → Share → Add to Home Screen. Local logs and custom routines stay on that device/browser. Use More → Export backup frequently. Avoid public hosting if your embedded meal plan is private.

index.html is not a standalone app install file. Do not expect saved data to sync automatically between devices.
